# Nosotros para Android

App de Android de **Nosotros** (distancia, calendario, ciclo, chat y series para dos).

## Descargar

- [Descargar la última versión (Nosotros.apk)](https://github.com/MiInfcl/nosotros-android/releases/latest/download/Nosotros.apk)
- [Ver todas las versiones](https://github.com/MiInfcl/nosotros-android/releases)

Al abrir el archivo, Android pedirá permitir instalar apps desde el navegador o el administrador de archivos que uses: actívalo solo para ese paso.

## Actualizaciones

La app busca sola las versiones nuevas en este repositorio (Ajustes → Actualizaciones).

### Numeración de las versiones

Cada versión es un release con la etiqueta `vN`, donde N es el número de versión de la app (el `versionCode` de Android): `v2` es la versión 1.1, `v3` la 1.2, `v4` la 1.3, `v5` la 1.4 y la siguiente será `v6` (1.5).

**Cambio de numeración:** brevemente se anunció que las etiquetas pasarían a ser la versión de la app (`v1.5`); se descartó y se mantiene `vN`, como hasta ahora. Las versiones 1.1 a 1.4 seguirán actualizándose solas.

## Versión web

La misma app funciona en el navegador: https://nosotros-app.xyz (código en [MiInfcl/nosotros-app](https://github.com/MiInfcl/nosotros-app)).
Las dos usan la misma cuenta y los mismos ajustes.
